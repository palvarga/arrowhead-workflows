Arrowhead Workflow

Interactive simulations of the two worked examples from Arrowhead Workflow Choreography: a Formal Definition of Recipes and their Execution Model, running on the Eclipse Arrowhead 4.6.2 executor model.

Temperature controlSimple demonstration: read, evaluate, switch, one Workflow Session per control period. Shared tool delivery in a forklift assembly plantWorked example: three concurrent line Sessions sharing one nutrunner through a leased tool crib. Intent to Recipe: shared-tool tighteningFrom an operator's intent to a validated Recipe: Translator drafts, Validator checks I1–I2 and V1–V10, compiled plan compared with the hand-authored one and run in the kit. Duck cell: intent to plan on fourteen workstationsExpert scenarios of the TDK 2026 rubber-duck cell (CNC tool wear, pallet height, cure windows): gold and trap plans through static validation, a digital-twin dry run and the benchmark oracle.
Source and runnable kits: github.com/palvarga/arrowhead-workflows
